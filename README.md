# 🎙️ Meet Recorder

**Meet Recorder** — это автономное легковесное приложение для Windows для автоматической фоновой записи и локальной транскрибации рабочих встреч (Google Meet, Яндекс.Телемост, Zoom, звонки в Telegram, трансляции).

Приложение работает **100% локально на вашем компьютере**, не передает звук или текст в облако и формирует структурированные `.md` протоколы с таймкодами и разделением реплик (`Вы` / `Участники встречи`).

---

## 🚀 Основные возможности

* **Двухканальная чистая аудиозапись**:
  * Канал 1: Ваш микрофон (с авто-усилением громкости).
  * Канал 2: Системные динамики (WASAPI Loopback) — слышно всех собеседников.
* **100% Локальная транскрибация (Faster-Whisper)**:
  * Распознавание речи без подключения к интернету.
  * Форматирование в удобные абзацы с таймкодами `[ЧЧ:ММ:СС]`.
  * Выбор модели: `small` (~500 МБ) или `medium` / `large-v3-turbo` (~1.5 ГБ).
  * Поддержка ускорения на видеокартах NVIDIA (CUDA).
* **Неблокирующая очередь (Queue FIFO)**:
  * Можно записывать встречи одну за другой — аудио сохраняется за 1 секунду, а транскрибация идет в фоновом режиме по очереди.
* **Автоматическая организация проектов**:
  * Для каждого проекта задается своя папка, куда сохраняются итоговые протоколы.
  * Именование файлов: `<Название встречи> - ЧЧ.ММ ДД.ММ.ГГГГ.md`.
* **Автоочистка кэша**:
  * Исходные тяжелые `.wav` файлы автоматически удаляются через 7 дней (настраивается от 1 до 90 дней), экономя место на диске.
* **Удобное управление**:
  * Глобальный хоткей старта/остановки (по умолчанию `Ctrl + Alt + Z`).
  * Плавающий индикатор с живым таймером на экране во время записи.
  * Работа в системном трее без открытых окон консоли.
  * Мастер первичной настройки (Onboarding Wizard) с живыми индикаторами громкости.

## 📦 Установка для пользователей

1. Скачайте инсталлятор **[MeetRecorder-Setup.exe](https://github.com/Zhdanov-av/meet-recorder/releases/latest)** из раздела [Releases](https://github.com/Zhdanov-av/meet-recorder/releases).
2. Запустите файл установки и следуйте простым подсказкам мастера.
3. При первом запуске откроется мастер настройки, который поможет проверить микрофон и системный звук, создать первый проект и загрузить модель Whisper.

## 🛠️ Разработка и запуск из исходного кода

```bash
# Клонирование репозитория
git clone https://github.com/Zhdanov-av/meet-recorder.git
cd meet-recorder

# Установка зависимостей
pip install -r requirements.txt

# Запуск приложения
python main.py
```

### Сборка установщика Windows (.exe):
1. Сборка бинарного пакета: `python build_exe.py`
2. Компиляция инсталлятора через Inno Setup: `iscc installer.iss`
